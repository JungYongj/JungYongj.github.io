베트남 공장 첫 MES 도입

어떻게 풀었나

DMC 라인 지그·SN 흐름

  1. 문제

    베트남 DMC 라인은 이번에 처음 MES를 적용하는 라인입니다. 기판이 BOT 공정부터 지그에 담겨 SN 단위로 흘러가는데, 이 흐름을 현장에서 처리할 화면은 설계서만 있고 새로 만들어야 했습니다.

  2. 고민

    베이킹 → TOP → BOT(지그 투입·SN 발번) → X-Ray → 매거진 → 본딩 → ASSY로 가는 동안 관리 단위가 자재 LOT → 지그 → SN → 매거진으로 바뀝니다. 스캐너로 끊김 없이 연속 스캔하면서도, 다른 작업지시에서 쓰는 지그·한도를 넘긴 지그·반대 면 지그 같은 잘못된 투입은 막아야 했습니다.

  3. 해결
    • TOP·BOT 지그 투입은 작업지시 → 메인 자재 LOT → 지그 연속 스캔으로 만들고, 포커스를 지그 칸에 붙여 두며 OK는 파랑, NG는 노랑과 경고음으로 구분했습니다.
    • 스캔할 때마다 작업지시 상태, 자재의 BOM·창고·유효기간·MSL·베이크 시간, 지그 상태와 사용·테이프 한도, 다른 작업지시 사용 여부를 서버에서 다시 확인하고, TOP 화면에 BOT 지그(또는 반대)를 찍으면 막았습니다.
    • BOT 지그 투입에서 지그 적재 수량만큼 SN을 발번해 지그와 연결하고, 이어서 매거진 지그 맵핑, DMC 개별실적(불량 분리·라벨 발행), 공정 생산실적 생성(설비 데이터 누락 시 수동 Track-In/Out) 화면을 만들었습니다.
    • 앞 스캔이 처리 중일 때 들어온 스캔은 NG로 돌려보내고, 초기화나 작업지시를 바꾼 뒤 늦게 도착한 응답은 버려 화면 값이 섞이지 않게 했습니다.
  4. 결과

    베트남 공장 기준정보로 작업지시 4개를 베이킹부터 ASSY까지 화면에서 차례로 진행해 보며 17가지 문제를 찾아 정리했습니다. 그중 BOT에서 메인 자재가 소진되지 않아 재고와 ERP 소비실적이 빠지던 문제는 지그 투입 때 SN마다 소진하도록 고쳤고, 지그 사용 횟수가 늘지 않던 원인도 찾아 바로잡았습니다.

진행 중

지금 하고 있는 일

2026년 11월부터 전자부품 SMT·조립 공장 MES 고도화 프로젝트에서 베트남 공장을 맡고 있습니다. 베트남 공장은 이번에 처음 MES를 적용하며, 2027년 1월 오픈을 앞두고 현장에서 쓸 화면과 기능을 개발하고 있습니다. 화면은 개발 환경 캡처이며 품번·LOT 등 고객 정보는 가렸습니다.

  • 제품군별 MES 전용 항목 입력, DMC 모델 관리·품목 매핑, DMC 품목 기준정보까지 품목 기준정보 신규 화면 4종을 개발했습니다. PCB 품목은 모델의 지그(JIG)에 자동으로 연결되게 했습니다.
  • DMC 라인 화면으로 TOP·BOT 지그 투입, 매거진 지그 맵핑, DMC 개별실적, 공정 생산실적 생성, 고객사 포장 라벨 발행, 고객사 연동 DB로 불량 정보를 보내는 화면을 개발했습니다.
  • 품목에 「LOT 라벨 입력 여부」를 새로 두고, 해당 품목은 작업지시를 확정할 때 라벨 값이 비어 있으면 확정을 막도록 했습니다.
  • 이미 ERP로 보낸 출하의 전기일을 고칠 수 있도록, 출하를 취소하고 바뀐 전기일로 다시 보내는 화면을 새로 만들었습니다.
  • 협력사 인보이스 조회 화면에 엑셀 다운로드를 추가하고, 내려받을 때 생기던 날짜 변환 오류를 고쳤습니다.
  • 지금은 포장까지 DMC 전체 흐름을 화면으로 이어 테스트하며, 지그 해제 시점처럼 남은 기준을 확인하고 있습니다.
