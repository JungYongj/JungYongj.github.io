사우디 현장 PL로 설비 200기와 연동되는 MES·HMI·POP 구축을 이끌었습니다.

어떻게 풀었나

설비 데이터를 MES 실적까지

  1. 문제

    주조·단조 공장 MES를 새로 구축하면서, 현장 설비의 PLC 데이터를 MES 실적까지 끊김 없이 이어야 했습니다. Historian 태그 타입과 MES DB 컬럼 타입이 어긋나면 실적 처리 오류가 날 수 있었습니다.

  2. 고민

    데이터 흐름을 수집 → 저장 → 시각화 → MES 연계 단계로 나누고, 태그를 추가하기 전에 Historian의 Event·Tag 정보와 MES DB L2 테이블 구조를 먼저 정의해 두는 구조로 잡았습니다.

  3. 해결
    • KEPServerEX로 PLC 데이터를 수집·표준화하고, Historian에 실시간·이력 데이터로 저장했습니다.
    • Intouch HMI로 설비 상태·알람·트렌드를 보여 주고, MES-HMI에서 한 번에 모니터링하게 했습니다.
    • C# Interface Program으로 Historian 태그와 MES DB 컬럼을 연결해 실적 데이터를 넘깁니다.
    • CNC 설비용 POP에서 작업 지시 조회, NC Program 확인·재요청, Start/End 실적, Loss 입력, 이벤트 로그를 처리합니다.
  4. 결과

    Historian 전송 누락률을 17.5%에서 0.3%로 줄였고, 태그 1만 건 등록을 자동화해 10시간 걸리던 일을 2시간으로 줄였습니다.

그 밖에 해낸 일

  1. Intouch HMI 42개 화면을 재구축하고 Alarm/Event 통합 뷰를 제공했습니다.
  2. 통역과 주간 미팅으로 벤더·설계사·사용자 사이의 소통을 조율하고 현장 관리자 교육을 맡았습니다.
  3. Kepware가 PLC와 TCP/IP로 통신하게 하고, 태그 이름을 기준으로 Intouch HMI와 Historian이 같은 데이터를 가져오는 구조를 만들었습니다.
  4. Historian은 구축에서 끝내지 않고 이중화까지 적용했습니다.
  5. Historian 데이터를 MES DB로 연계하는 인터페이스 프로그램과 CNC용 POP 프로그램을 개발했습니다.
